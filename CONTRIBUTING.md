# Hướng Dẫn Đóng Góp - Control Test

Cảm ơn bạn muốn đóng góp cho dự án này! Tài liệu này hướng dẫn cách bạn có thể giúp cải tiến project.

## 📋 Quy Trình Đóng Góp

### 1. Fork & Clone Repository
```bash
git clone https://github.com/Finn10205/control-test.git
cd control-test
git checkout -b feature/your-feature-name
```

### 2. Code & Commit
- Viết code theo chuẩn C# (.NET)
- Commit message nên rõ ràng và mô tả (ví dụ: `Add window detection feature`)
- Tránh commit quá lớn - chia thành các commit nhỏ, logic

### 3. Push & Pull Request
```bash
git push origin feature/your-feature-name
```
Sau đó, tạo Pull Request trên GitHub với mô tả chi tiết.
